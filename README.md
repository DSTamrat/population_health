# **Population Health Analytics & Risk Stratification Dashboard**  
### *Applicable for CareFirst, Kaiser Permanente, Optum, and other health plans*

---

## **📌 Overview**
A fully‑built, end‑to‑end demonstration of how a health plan can transform **raw member data** into **actionable population health intelligence**.  
This project uses **synthetic healthcare data** to safely simulate real‑world workflows without exposing PHI, and delivers insights through a clean, interactive **Streamlit dashboard** designed for senior leadership, clinical operations, and care‑management teams.

---

## **🚑 The Problem**
Health plans often struggle with:

- Fragmented, messy, inconsistent data  
- Slow manual processes for identifying high‑risk members  
- Limited visibility into population‑level trends  
- No unified view for executives or care teams  

This project solves those challenges by building a unified pipeline:

**Ingestion → ETL → Machine Learning → Salesforce‑Ready Outputs → Executive Dashboard**

---

## **🎯 Objectives**
- Build a realistic healthcare data pipeline using synthetic data  
- Clean and standardize raw data using enterprise‑grade ETL techniques  
- Predict member risk using a machine‑learning model  
- Assign members to actionable risk tiers  
- Generate a **Salesforce Health Cloud–ready** payload  
- Present insights in a simple, intuitive, executive‑friendly dashboard  

---

## **🛠️ Methodology & Tools**
- **Data Engineering:** Pandas, NumPy, feature engineering, outlier handling, imputation  
- **Machine Learning:** Random Forest classifier for risk prediction  
- **Visualization:** Plotly interactive charts  
- **Dashboard:** Streamlit multi‑page interface  
- **Operational Output:** Salesforce‑formatted payload for care‑management workflows  

---

## **🌲 Model Used — Random Forest Classifier**
Random Forest was selected because it:

- Handles messy healthcare data well  
- Performs reliably with nonlinear patterns  
- Is interpretable for clinical and operational stakeholders  

**Plain‑English intuition:**  
Each tree makes its own prediction, and the forest averages them — producing a stable, trustworthy risk score for each member.

---

## **📈 Key Outcomes**
- Cleaned and enriched member dataset  
- Predictive risk scores for every member  
- Tiered segmentation: **Low**, **Moderate**, **High / CMS Focus**  
- Salesforce‑ready operational payload  
- Executive dashboard with KPIs, charts, and drill‑downs  

---

## **📊 Why the Dashboard Matters**
The dashboard turns a complex pipeline into a **simple, visual story**.

Executives can instantly see:

- How many members are high‑risk  
- What drives risk  
- Where costs are concentrated  
- Which members need outreach  
- How the system works end‑to‑end  

This is a tool for **real decision‑making**, not just analysis.

---

## **💡 Lessons Learned**
- Clean data is the foundation of accurate modeling  
- Interpretability is essential in healthcare analytics  
- Operational outputs matter as much as predictions  
- Dashboards must be simple, intuitive, and visually clear  
- End‑to‑end thinking (ingestion → action) is what employers value most
